Canonical architecture inspected at the pinned SHA:
- TH2M is monolithic; the DOF table contains gas pressure, capillary pressure,
  temperature, and displacement.
- TH2MProcess assembly, post-timestep state commit, and secondary-variable
  computation use the process active-element set.
- TH2MLocalAssembler owns current_states_, prev_states_, and material_states_;
  material state variables are explicitly initialized and pushed back.

Frozen staged-construction contract:
- inactive means true process-wide void: no mechanics, gas storage/transport,
  liquid storage/transport, thermal storage/conduction, or TH2M coupling;
- activation uses the last converged displacement as mechanical birth/reference
  configuration;
- explicit placement state owns p_g,0, p_c,0, T_0; liquid pressure remains
  derived from the TH2M primary pressure convention;
- newly activated material gets fresh constitutive/material state and zero
  birth stress unless an explicit placement stress is provided later;
- full physical operators are used; no stiffness-to-zero scaling, residual
  homotopy, or material homotopy is part of the contract;
- construction equilibrium continuation keeps physical time constant.

Established-method alignment checked before TH2M runtime mutation:
- Abaqus Model Change: staged element removal/addition is an element-status
  operation rather than a constitutive stiffness-ramp requirement.
- PLAXIS Staged Construction: activation/deactivation and material assignment
  are phase-level construction operations.
- FLAC3D/Itasca: null zones are considered absent; current documentation states
  the null state applies to mechanical, thermal, and fluid processes, and newly
  created zones start with zero stress and no constitutive model until assigned.
  Sequential-model documentation separately warns that stiffness changes alone
  do not create a new equilibrium response and that construction alterations
  create the unbalanced forces to be solved.
